# 📚 Study Tracker ⏱️

A simple Python (CLI) program to help you **track your study sessions** and stay on top of your academic goals!  
It calculates how long you've studied, stores each session in a database, and helps you monitor progress toward your **total study hours per subject**.

---

## ✨ Features

- ⏳ Calculate duration of each study session
- 🗃️ Save session data to a local database
- 📈 Track total study time per subject
- 🎯 Stay focused on your study goals

---

## 🛠️ How It Works

1. Define your subject and set a goal for total study hours.
2. Start a study session.
3. End the session when you're done.
4. The program calculates the time spent.
5. It adds the session to a database with subject info.
6. You can view your total study time per subject anytime.

---

## 📦 Requirements

- Python 3.x
